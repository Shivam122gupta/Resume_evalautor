# HireLens

HireLens is a resume evaluation tool that helps compare resumes with a given job description.

The basic idea is simple: instead of manually going through every resume, you can upload the job description and multiple resumes, and the system evaluates the candidates and shows the results in one place.

I built this project to explore how AI/NLP can be used in a practical recruitment workflow.

## What it does

* Add a job description
* Upload one or multiple resumes
* Evaluate resumes using the backend AI pipeline
* Get a score for each candidate
* See matched and missing skills
* Compare candidates
* Open detailed candidate results
* View previous evaluations in history

The frontend and backend are kept separate so that the evaluation logic can be changed without having to rebuild the UI.

## Screens

### Resume Evaluation

The main page is where the job description and resumes are added.

### Candidate Results

After evaluation, candidates are ranked based on how well their resume matches the job requirements.

### Candidate Details

Each candidate has a detailed view containing the evaluation score, skills, strengths, weaknesses and recommendation.

### History

Previous evaluations can be accessed from the history section.

## Running Locally

Clone the repository:

```bash
git clone <your-repository-url>
cd HireLens
```

### Backend

Go to the backend folder:

```bash
cd backend
```

Create a virtual environment:

```bash
python -m venv .venv
```

Activate it on Windows:

```powershell
.venv\Scripts\activate
```

Install dependencies:

```bash
pip install -r requirements.txt
```

Start the API:

```bash
uvicorn main:app --reload
```

The backend will normally be available at:

```text
http://127.0.0.1:8000
```

### Frontend

Open another terminal:

```bash
cd frontend
npm install
npm run dev
```

Then open:

```text
http://localhost:5173
```

Make sure the frontend API configuration points to the backend running locally.

## How the application works

The flow is:

```text
Job Description
       |
       v
Upload Resumes
       |
       v
Frontend sends files to FastAPI
       |
       v
Resume Processing
       |
       v
AI / NLP Evaluation
       |
       v
Candidate Scores & Analysis
       |
       v
Results shown in HireLens
```

## Why I built it

Resume screening is one of those tasks that looks simple until you have to go through a large number of resumes.

I wanted to build something where I could work on the complete flow instead of only training a model:

* frontend
* API
* file upload
* resume processing
* AI evaluation
* result presentation
* history

It also gave me a chance to understand how an AI feature can be connected to an actual application.
